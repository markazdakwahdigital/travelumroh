# MDD Design System — Master Reference

Status: LOCKED visual direction for Travel Umrah MDD.

The approved visual reference supplied in the project is the primary UI direction.

## Core identity
- Deep navy / royal blue base
- Gold accents and Islamic geometric ornament
- White/light content canvas
- Ka'bah / Masjid al-Haram hero photography
- Premium Islamic arch treatment
- Clean compact dashboard density
- Soft depth, subtle glow and restrained 3D treatment

## Dashboard composition
1. Branded sidebar
2. Ka'bah hero with MARKAZ DAKWAH DIGITAL
3. Four KPI cards
4. Revenue chart + Jamaah status donut + nearest departures
5. CRM pipeline with six stage cards
6. Latest activity
7. Responsive mobile shortcuts and bottom navigation

## Responsive rule
Desktop/iPad preserve information density. Android/iPhone use the same visual language but reflow content instead of shrinking the desktop canvas.

## Content rule
Visual composition may follow the approved reference closely. Illustrative names, operational records and figures shown only in design references must not be treated as verified production data.
